# poultry-guard-ai
> Real-time poultry health monitoring using YOLOv8 with an accessibility-focused UI/UX.

---

### 🚀 About This Project
PoultryGuard AI is an intersection of **Computer Vision** and **Human-Computer Interaction**. This project addresses the challenge of monitoring livestock health in high-noise, dust-heavy farm environments. 

By optimizing **YOLOv8** for real-time edge detection and designing a **high-contrast, high-utility interface**, I am building a tool that bridges the gap between complex AI models and practical, on-the-ground farming.
